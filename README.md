# Automation & Systems Portfolio
### Ervhyne Jesalva

This repository contains professional-grade automation solutions built primarily with **Google Apps Script**, **JavaScript**, and **Supabase**.

## Featured Projects

### 1. APS Production Workflow Engine
- **Problem:** Manual tracking of high-volume activity submissions.
- **Solution:** A centralized queue with role-based approval logic and automated notifications.
- **Tech:** Google Apps Script, HTML Service, GmailApp.

### 2. ADM Real-Time Reservation System
- **Problem:** Data collisions when multiple users attempt to claim the same row.
- **Solution:** A script-driven engine managing concurrent entries for real-time reporting.
- **Tech:** Google Apps Script.
